# dyscalculia_synthetic - SIMULATED DATA (not real children)

Generated by `ml/src/dyscalculia_synthetic.py` (seed in `generator_params.json`). Use only to develop and test the dyscalculia pipeline before real game data exists. **Never report accuracy on this data as a real-world or clinical result.**

* `children.csv` - child_id, age, gender, dyscalculia label (5 % label noise)
* `trials.csv` - trial-level logs of the five game tasks (Q11 subitize, Q12 magnitude, Q13 numberline, Q14 sequence, Q15 arithmetic), in the same shape the game should export
* `ground_truth_DO_NOT_TRAIN.csv` - latent abilities and true status, used only to verify the XAI
